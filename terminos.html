01Qué es este proyectoWhat this project is

QWATT es un proyecto en desarrollo del sprint Instawards Chile (desde el 19 oct 2026), de Jay Kim y Diego Ostertag. Es un verificador de código abierto que convierte lecturas de medidores solares en constancias que cualquiera puede volver a comprobar solo con datos públicos, en Stellar testnet.QWATT is a project in development in the Instawards Chile sprint (since 19 Oct 2026), by Jay Kim and Diego Ostertag. It is an open-source verifier that turns solar meter readings into records anyone can re-check from public data alone, on Stellar testnet.

Las páginas de agosto 2026 son trabajo previo, rotuladas TESTNET, PROTOTIPO o PLANIFICADO. Toda la entrada del sprint es simulada.The August 2026 pages are prior work, labeled TESTNET, PROTOTYPE or PLANNED. All input during the sprint is simulated.

Stellar testnet se reinicia periódicamente y borra cuentas y datos. Lo que este sitio lee de testnet puede desaparecer en un reinicio; la evidencia publicada en el repositorio queda.Stellar testnet is reset from time to time, which erases accounts and data. What this site reads from testnet may disappear in a reset; the evidence published in the repository stays.

02Sin oferta y sin asesoríaNo offer, no advice

Este sitio no ofrece nada, no da asesoría legal ni tributaria y no está registrado ante ningún regulador. Nada de lo que muestra es una recomendación.This site offers nothing, gives no legal or tax advice and is not registered with any regulator. Nothing it shows is a recommendation.

La red principal de Stellar y cualquier uso del activo QWATT más allá del anclaje están fuera del acuerdo de arquitectura v3. El activo QWATT de testnet, creado en agosto (trabajo previo), solo se usa en cada transacción de anclaje como el pago marcador fijo: siempre el mismo y el mínimo que admite Stellar; no representa energía.The Stellar main network and any use of the QWATT asset beyond anchoring are outside architecture freeze v3. The QWATT testnet asset, created in August (prior work), is used only in each anchoring transaction as the fixed marker payment: always the same, the smallest Stellar allows; it does not represent energy.

QWATT es un proyecto en desarrollo que opera solo en Stellar testnet. QWATT no es electricidad, ni una inversión, ni un valor o instrumento financiero, ni un certificado de energía renovable (REC), ni un crédito de carbono. No tiene precio y no se vende.

QWATT is a project in development that runs only on Stellar testnet. QWATT is not electricity, not an investment, not a security or financial instrument, not a renewable energy certificate (REC), and not a carbon credit. It has no price and is not for sale.

03LímitesLimits

Lo que el sprint no muestra:What the sprint does not show:

  • una instalación física que haya producido energía;a physical installation that produced energy;
  • la exactitud de un medidor;meter accuracy;
  • que los umbrales de los filtros sirvan para un sitio real;that the filter thresholds suit a real site;
  • que el verificador sea independiente como organización (hoy lo opera nuestro propio equipo: es independiente en código y en datos);that the verifier is independent as an organization (today our own team operates it: it is independent in code and data);
  • nada sobre la red principal ni sobre la custodia de claves en producción.anything about the main network or production key custody.

Un anclaje no se puede editar: lo que entra a un ledger de Stellar queda ahí. Errores de software o fallas de red pueden producir resultados incorrectos; por eso todo es reproducible con npm test y datos públicos, y cada página dice de dónde sale cada número.An anchor cannot be edited: what enters a Stellar ledger stays there. Software errors or network failures can produce wrong results; that is why everything is reproducible with npm test and public data, and every page says where each number comes from.

05ClavesKeys

  • Ninguna página de qwatt.org genera, pide, guarda ni muestra claves secretas, ni firma transacciones.No qwatt.org page generates, asks for, stores or displays secret keys, or signs transactions.
  • El equipo de QWATT nunca te pedirá tu clave secreta (S…); las claves públicas (G…) sí se pueden compartir.The QWATT team will never ask for your secret key (S…); public keys (G…) can be shared.
  • Verifica siempre el dominio qwatt.org.Always check the qwatt.org domain.
  • Las claves del anclaje se crean con stellar-cli en la máquina que las usa (semana 2).The anchoring keys are created with stellar-cli on the machine that uses them (week 2).
  • Si se pierde una de las tres, el anclaje sigue pero los firmantes ya no se pueden cambiar; si se pierden dos, el anclaje se detiene y la recuperación es una cuenta nueva.If one of the three is lost, anchoring continues but signers can no longer be changed; if two are lost, anchoring stops and recovery means a new account.

06PrivacidadPrivacy

No usamos analítica ni cookies propias, y no hay formularios.We use no analytics and no cookies of our own, and there are no forms.

La página de conciliación tiene campos para la URL de un feed de evidencia y una cuenta (y, si quieres, un servidor Horizon y tres claves públicas): lo que escribes ahí solo sirve para leer datos públicos desde tu navegador. Al conciliar, la página lo escribe en su propia dirección, así que queda en el historial de tu navegador y, como cualquier dirección, llega a qwatt.org cuando esa página se carga o se recarga con ella (por ejemplo, al abrir un enlace a esa comprobación).The reconciliation page has fields for the URL of an evidence feed and an account (and, if you want, a Horizon server and three public keys): what you type there is only used to read public data from your browser. When you reconcile, the page writes it into its own address, so it stays in your browser history and, like any address, reaches qwatt.org when that page is loaded or reloaded with it (for example, when a link to that check is opened).

Solo el idioma, el tema día/noche y el estado del menú se guardan en el almacenamiento local de tu navegador. La página de custodia de claves tiene un botón que, si lo pulsas, borra de tu navegador dos claves que podían haber dejado las herramientas de agosto, sin leerlas.Only the language, the day/night theme and the menu state are kept in your browser's local storage. The key custody page has a button that, if you press it, deletes from your browser two keys the August tools may have left, without reading them.

Tu navegador se conecta solo a:Your browser connects only to:

  • qwatt.org (este sitio, alojado en Vercel)qwatt.org (this site, hosted on Vercel)
  • horizon-testnet.stellar.org (datos públicos de Stellar testnet, solo lectura)horizon-testnet.stellar.org (public Stellar testnet data, read-only)
  • api.github.com (solo la página de conciliación: el último commit del repositorio público de evidencia, sin cuenta; GitHub admite 60 consultas por hora por dirección IP)api.github.com (only the reconciliation page: the latest commit of the public evidence repository, with no account; GitHub allows 60 requests an hour per IP address)
  • raw.githubusercontent.com (solo la página de conciliación: los archivos del repositorio público de evidencia en ese commit, solo lectura)raw.githubusercontent.com (only the reconciliation page: the files of the public evidence repository at that commit, read-only)
  • fonts.googleapis.com y fonts.gstatic.com (Google Fonts, tipografías)fonts.googleapis.com and fonts.gstatic.com (Google Fonts, typefaces)

El navegador mismo lo hace cumplir: el sitio declara esa lista en su política de seguridad de contenido, y bloquea cualquier otro destino. Los enlaces a stellar.expert, GitHub, YouTube y X abren esos sitios, con sus propias políticas.The browser itself enforces it: the site declares that list in its content security policy, which blocks any other destination. Links to stellar.expert, GitHub, YouTube and X open those sites, under their own policies.

07GlosarioGlossary

StellarStellar
Una red pública de registro. XLM cubre las comisiones de la red y en testnet no tiene valor.A public ledger network. XLM covers the network's fees and has no value on testnet.
TestnetTestnet
La red de pruebas de Stellar: funciona como la red principal, pero nada en ella tiene valor y se reinicia periódicamente, borrando cuentas y datos.Stellar's test network: it works like the main network, but nothing on it has value and it is reset from time to time, erasing accounts and data.
HorizonHorizon
La interfaz pública de Stellar. Cualquiera puede leer en ella cuentas, firmantes, umbrales y transacciones, sin cuenta y sin claves.Stellar's public interface. Anyone can read accounts, signers, thresholds and transactions on it, with no account and no keys.
Clave pública y clave secretaPublic key and secret key
La pública (empieza con G) es la dirección de una cuenta y se puede compartir. La secreta (empieza con S) firma transacciones: quien la tiene puede firmar lo que esa clave permite. Nunca se comparte ni se pega en una web.The public one (starts with G) is an account's address and can be shared. The secret one (starts with S) signs transactions: whoever holds it can sign what that key allows. It is never shared or pasted into a website.
Línea de confianzaTrustline
La autorización que una cuenta abre para poder recibir un activo concreto. Este sitio solo muestra si existe (sí o no): la cuenta de anclaje la necesita para el pago marcador.The authorization an account opens to be able to receive a specific asset. This site only shows whether it exists (yes or no): the anchoring account needs it for the marker payment.
Memo (QW#n)Memo (QW#n)
Un texto corto en la transacción; QWATT lo usa para numerar cada anclaje: QW#0, QW#1… Este sitio no muestra ningún otro memo.A short text in the transaction; QWATT uses it to number each anchor: QW#0, QW#1… This site shows no other memo.
LoteBatch
Doce intervalos de 5 minutos (una hora de lecturas) publicados juntos, con su huella, la huella del lote anterior, su energía y el total acumulado en milivatios-hora.Twelve 5-minute intervals (one hour of readings) published together, with its fingerprint, the previous batch's fingerprint, its energy and the running total in milliwatt-hours.
Lote rechazadoRejected batch
Un lote que no pasa la comprobación: se publica igual, con su motivo, nunca se ancla y, desde la semana 1, no suma energía al total.A batch that fails the check: it is published anyway, with its reason, is never anchored and, since week 1, adds no energy to the total.
HuellaFingerprint
El SHA-256 de un lote en su forma canónica: 64 caracteres que cambian por completo si cambia un solo byte.The SHA-256 of a batch in its canonical form: 64 characters that change completely if a single byte changes.
Cadena de lotesBatch chain
Cada lote lleva la huella del anterior (prev_hash), así que cambiar uno rompe todos los siguientes. El primero apunta a 64 ceros.Each batch carries the previous one's fingerprint (prev_hash), so changing one breaks every later one. The first points to 64 zeros.
AnclarAnchor
Escribir en Stellar testnet la huella y el total acumulado de un lote aceptado, en una transacción atómica firmada por 2 de 3 claves.To write an accepted batch's fingerprint and running total on Stellar testnet, in one atomic transaction signed by 2 of 3 keys.
Transacción atómicaAtomic transaction
Varias operaciones que se aplican todas o ninguna: así un anclaje deja huella, total y pago marcador juntos, o nada.Several operations that apply all together or not at all: that is how an anchor leaves fingerprint, total and marker payment together, or nothing.
Pago marcadorMarker payment
Un pago fijo y mínimo del activo QWATT de testnet en cada transacción de anclaje. Solo marca la transacción.A fixed, minimal payment of the QWATT testnet asset in each anchoring transaction. It only marks the transaction.
ProponenteProposer
El servicio que arma y publica cada lote, construye su transacción de anclaje y la firma. Nunca la envía.The service that builds and publishes each batch, builds its anchoring transaction and signs it. It never submits it.
Verificador independienteIndependent verifier
Un servicio con su propia clave que vuelve a revisar cada lote solo con datos públicos, reconstruye la transacción y cofirma si es idéntica. Independiente en código y datos, no en organización.A service with its own key that re-checks every batch from public data only, rebuilds the transaction and co-signs if it is identical. Independent in code and data, not in organization.
Firmantes 2 de 32-of-3 signers
Las tres claves que podrán firmar por la cuenta de anclaje: la del proponente, la del verificador y la de una persona externa al equipo. Dos cualquiera bastan para anclar; ninguna sola basta para nada.The three keys that will be able to sign for the anchoring account: the proposer's, the verifier's and one held by a person outside the team. Any two can anchor; none alone can do anything.
Umbrales 2/2/3Thresholds 2/2/3
Las firmas que exigirá la cuenta de anclaje: 2 para cualquier transacción, 2 para anclar y 3 para cambiar firmantes o umbrales.The signatures the anchoring account will require: 2 for any transaction, 2 to anchor and 3 to change signers or thresholds.
Filtros de verificación (G0–G3)Verification filters (G0–G3)
Cuatro reglas que cada intervalo debe pasar: G0 plausibilidad, G1 techo de placa, G2 sol sobre el horizonte, G3 acuerdo entre los dos medidores. Si una falla, el intervalo se rechaza con un motivo público.Four rules each interval must pass: G0 plausibility, G1 nameplate ceiling, G2 sun above the horizon, G3 agreement between the two meters. If one fails, the interval is refused with a public reason.
Cuenta que creó el activoAccount that created the asset
La cuenta de testnet que creó el activo QWATT el 22 ago 2026, en el hackathon (trabajo previo). Una sola clave la controla; no es la cuenta de anclaje.The testnet account that created the QWATT asset on 22 Aug 2026, at the hackathon (prior work). A single key controls it; it is not the anchoring account.
Destino del pago marcadorMarker-payment destination
La cuenta de testnet de agosto 2026 que recibe el pago marcador de cada anclaje en la configuración de ejemplo; el destino definitivo se fija en la semana 2.The August 2026 testnet account that receives each anchor's marker payment in the example configuration; the final destination is set in week 2.
Feed público de evidenciaPublic evidence feed
Los archivos que cualquiera puede descargar para comprobar una corrida: cada lote, sus registros y sus lecturas crudas.The files anyone can download to check a run: each batch, its registers and its raw readings.
Raíz de lecturas crudas (samples_root)Raw-reading root (samples_root)
Una huella de todas las lecturas crudas de un lote, desde la semana 2.A fingerprint of every raw reading in a batch, from week 2.
Huella de transacciónTransaction hash
El SHA-256 de una transacción de Stellar sin sus firmas; por eso las pruebas A, B y C tienen la misma.The SHA-256 of a Stellar transaction without its signatures; that is why tests A, B and C share one.
Firma Ed25519Ed25519 signature
El tipo de firma de Stellar; tu navegador puede verificarla con WebCrypto, sin conocer ninguna clave secreta.Stellar's signature type; your browser can verify it with WebCrypto, without knowing any secret key.
CICI
Integración continua: las pruebas automáticas que GitHub corre en cada cambio del repositorio. Una corrida en rojo antes de un arreglo y en verde después es la evidencia de ese arreglo.Continuous integration: the automated tests GitHub runs on every change to the repository. A run that is red before a fix and green after it is the evidence for that fix.
Etiqueta (dia-1, semana-1)Tag (dia-1, semana-1)
Un nombre fijo para un commit del repositorio: dia-1 marca dónde empezó el sprint y semana-1, la entrega de la semana 1.A fixed name for a repository commit: dia-1 marks where the sprint started and semana-1 the week-1 delivery.
Acuerdo de arquitecturaArchitecture freeze
El documento que fija el formato de la evidencia, las reglas de firma y de rechazo, y el plan de cada semana. La versión 3 la acordaron los dos fundadores el miércoles 21 oct.The document that sets the evidence format, the signing and rejection rules, and the plan for each week. Version 3 was agreed by both founders on Wednesday 21 Oct.
